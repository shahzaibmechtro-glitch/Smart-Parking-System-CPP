# Smart Parking Management System Using ESP32 and C++

## Project Overview
This project is an IoT-based Smart Parking Management System developed using ESP32 and C++. The system verifies ESP32 connectivity before execution and provides secure login authentication using username and password.

The application manages parking records for 100 vehicles stored in an Excel/database file.

## Features
- ESP32 connectivity verification
- Secure login authentication
- Store and manage vehicle records
- Search vehicles by Spot ID
- Display complete parking database
- Update parking status (IN/OUT)
- Edit and replace vehicle records
- Excel file integration

## Vehicle Data Includes
- Spot ID
- Vehicle Number
- Vehicle Type
- Owner Name
- Status (IN/OUT)
